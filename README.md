# Scandiweb E-commerce Application

A full-stack e-commerce application built with React frontend and PHP backend.

## Links

- **Live Website**: https://heroic-treacle-6ef6d0.netlify.app/
- **GitHub Repository**: https://github.com/yourusername/scandiweb-ecommerce
- **API Documentation**: https://rsx.onlinewebshop.net/api/products.php

## Tech Stack

- **Frontend**: React, Vite, Tailwind CSS
- **Backend**: PHP, MySQL, GraphQL
- **Testing**: Vitest, Playwright

## Quick Start

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
composer install
php data/import-data.php
```

## Features

- Product catalog with categories (All, Clothes, Tech)
- Shopping cart with real-time updates
- Product detail pages with image galleries
- Responsive design for mobile and desktop
- GraphQL and REST API support

## Available Scripts

```bash
npm run dev      # Start development server
npm run build    # Build for production
npm test         # Run tests
```
